# Support

If you need help with this repository, use one of the following channels:

- Open a GitHub issue using the appropriate issue template.
- For general questions, suggestions, or feedback, email [contact@devcatalyst.in](mailto:contact@devcatalyst.in?cc=devcatalyst.2025%40gmail.com).
- For partnerships or collaboration proposals, email [partnerships@devcatalyst.in](mailto:partnerships@devcatalyst.in?cc=devcatalyst.2025%40gmail.com).
- For security vulnerabilities, follow the private reporting process in [SECURITY.md](SECURITY.md).

Please CC **devcatalyst.2025@gmail.com** in every email so the team does not miss your message. The email links above include this CC automatically.

When asking for help, please include:

- What you expected to happen
- What actually happened
- Steps to reproduce (if relevant)
- Screenshots or logs (if relevant)
