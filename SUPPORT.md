# Support

If you need help with this repository, use one of the following channels:

- Open a GitHub issue using the appropriate issue template.
- For general questions or collaboration inquiries, email **contact@devcatalyst.in**.
- For security vulnerabilities, follow the private reporting process in [SECURITY.md](SECURITY.md).

When asking for help, please include:

- What you expected to happen
- What actually happened
- Steps to reproduce (if relevant)
- Screenshots or logs (if relevant)
