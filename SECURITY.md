# Security Policy

## Supported Versions

Security updates are provided for the latest commit on the default branch.

## Reporting a Vulnerability

Please do **not** open public GitHub issues for security reports.

Instead, report vulnerabilities privately by emailing:

- [contact@devcatalyst.in](mailto:contact@devcatalyst.in?cc=devcatalyst.2025%40gmail.com)

Please CC **devcatalyst.2025@gmail.com** so the team receives the report. The email link includes this CC automatically.

Include as much detail as possible:

- A clear description of the vulnerability
- Reproduction steps or proof of concept
- Potential impact
- Suggested remediation (if available)

## Response expectations

- We will acknowledge receipt within 3 business days.
- We will validate the report and share remediation status updates.
- After a fix is available, we will coordinate disclosure timing when applicable.
